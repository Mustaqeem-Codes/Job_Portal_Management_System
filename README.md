🏢 Job Portal Management System (JPMS)

A desktop-based job portal application built in C# with Oracle Database, designed to replicate the functionality of a real-world job portal. This project demonstrates multi-user management, database integration, and object-oriented programming concepts.

✨ Features

👨‍💼 Employer
Add, update, delete, and search job postings
Manage personal details
View and manage applications for their jobs only
Accept/reject candidates
Schedule interviews with preferred candidates

👩‍💻 Candidate
Create, update, and delete profile details
Browse all available job postings
View detailed job descriptions
Apply to jobs using a ready-made template form
Track application status (pending, selected, rejected)
View interview schedule when selected

⚙️ Tech Stack

Language: C# (OOP, Classes)
Database: Oracle (SQL, queries, persistence)
IDE: Visual Studio Community
Architecture: Desktop application with website-like functionality

📂 Project Setup
Download or Clone Repository
Open in Visual Studio Community
File → Open Project → Select .sln file
Database Setup
In Oracle Database create database schema and tables as given in txt file
Configure database connection string inside the project
Run the Project
Build & Run in Visual Studio
Start exploring as Employer or Candidate
